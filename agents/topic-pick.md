# Topic Pick Agent

> 국내 축구 커뮤니티에서 지금 가장 뜨거운 이슈 1건을 골라 오늘의 주제로 확정한다.
> 직접 작업하고 파일을 만든 뒤 종료한다 (백그라운드 자식 에이전트 금지).

## 출력
`output/_topic/오늘주제_[YYYY-MM-DD].txt` 1개 파일. 맨 위 첫 줄은 반드시
`주제: <한 줄 주제>` (예: `주제: 이강인 PSG 벤치 논란과 이적설`).
이어서 선정 근거(어느 커뮤니티 몇 개 글/댓글 반응, 후보 3~5개와 탈락 사유)를 짧게 적는다.

## 조사 소스 (오늘 날짜 기준 최근 24~48시간)
**1순위: Claude in Chrome 도구(mcp__claude-in-chrome__*)로 사용자의 실제 Chrome에서 직접 연다.**
도구가 지연 로드(deferred)면 ToolSearch 한 번으로 `tabs_context_mcp, tabs_create_mcp, navigate, get_page_text, tabs_close_mcp`를 같이 불러온다.
새 탭을 만들어 작업하고, 끝나면 반드시 닫는다.
- 에펨코리아 **해외축구** `https://www.fmkorea.com/football_world`: 페이지 하단의 **실시간 인기 키워드 순위**와
  상단 **"인기" 탭**(추천순)을 읽는다. 기본 목록(최신순)은 잡글이 많아 참고만 한다.
- 에펨코리아 **축구소식통**(이적·속보 게시판): 같은 방식으로 인기글을 읽는다. 주소를 모르면 해외축구 게시판 메뉴/검색에서 찾는다.
- 보조: 디시 해외축구 갤러리 개념글, 네이버·다음 스포츠 많이 본 뉴스(이쪽은 WebFetch 가능).
- 소스 최소 2곳(또는 키워드 순위 + 인기글)에서 반복 언급된 이슈만 "핫"으로 인정.

**Chrome 연결 재시도 (필수):** 도구가 목록에 안 보이면 `ToolSearch`로 `claude-in-chrome`을 검색해 불러온다.
`tabs_context_mcp`가 실패하거나 도구가 없으면 곧바로 포기하지 말고 `Start-Sleep 20`(Bash `sleep 20`) 후 최대 2회 더 재시도한다
(확장·네이티브 호스트가 늦게 붙는 경우가 많았다). 3회 모두 실패했을 때만 아래 대체 경로로 간다.
결과 파일에 시도 횟수와 실패 메시지를 적는다.

**Chrome 도구가 없거나 연결 실패 시:** WebFetch/WebSearch(`site:fmkorea.com` 등)로 대체해도 되지만,
봇 차단 우회(User-Agent 위장 등)는 하지 않는다. WebFetch 결과가 오늘 날짜와 안 맞는 옛 스냅샷이면 신뢰하지 말고,
그래도 뉴스 헤드라인으로 핫이슈를 확신할 수 없으면 FALLBACK 처리한다.

## 선정 원칙 (2026-11-12 개편: 화제성 → 검색 수요 × 약한 경쟁)
커뮤니티 핫이슈는 **후보 풀**일 뿐이다. 아래 순서로 걸러 최종 주제를 정한다.
1. 후보: 여러 커뮤니티(키워드 순위 + 인기글 등 2곳 이상)에서 반복 언급된 이슈 3~5건.
2. **한국 선수 연결 필수.** 후보를 한국 선수(해외파·유망주·대표팀)에게 미치는 영향/관련 질문으로 바꿀 수 있어야 한다.
   연결이 안 되는 후보(예: 맨유 감독 선임, 맨시티 부진 자체)는 탈락. 예: 이강인 PSG 벤치 → "이강인 선발 제외 이유와 다음 경기 출전 전망".
3. **롱테일 제목.** `선수 이름 + 구체적 질문/상황` 형태로 쓴다(예: "이한범 선발 출전 여부", "김지수 부상 복귀 시점").
   포괄적 이슈명("맨유 감독 논란")만 있는 주제는 금지.
4. **네이버 검색 수요 확인 (1회).** **네이버 스포츠/검색 페이지는 Chrome 도구가 safety restrictions로 차단하므로 쓰지 않는다(2026-11-16 FALLBACK 원인).**
   대신 Bash `curl -s "https://ac.search.naver.com/nx/ac?q=<URL인코딩 선수이름>&con=0&frm=nv&ans=2&r_format=json&r_enc=UTF-8&r_unicode=0&t_koreng=1&run=2&rev=4&q_enc=UTF-8&st=100"`
   로 자동완성(`items`)을 읽는다 (인증 불필요, 차단 없음 확인됨). 자동완성에 `<선수> 출전/부상/골/이적` 등이 뜨면 수요 있음.
   기존 설명: 네이버 자동완성/연관검색어(또는 검색 결과 수·기사 수)로 해당 선수 키워드 수요가 있는지,
   언론이 이미 도배했는지 본다. 도배됐으면 경쟁 약한 선수·각도로 바꾼다. 확인 방법과 결과를 파일에 적는다.
5. `output/` 최근 2주 내 이미 다룬 선수·이슈는 제외 (폴더명 확인).
6. 루머·낚시성은 신뢰 가능한 보도가 뒷받침될 때만. 확정 사실이 없으면 "전망/논란" 각도로 잡되 확정형으로 쓰지 않는다.
7. 동급이면 경쟁 약한 쪽(기사 적은 선수·이슈)을 고른다.

## 2단계 선정 (2026-11-16: 한국 선수 롱테일 우선 → 없으면 핫이슈)
1. **우선:** 위 선정 원칙대로 한국 선수 연결 롱테일 주제를 찾는다. 커뮤니티에 한국 선수 글이 없으면
   최근 대표팀·해외파 소식(WebSearch)에서 1순위 후보 선수(이한범·이재성·조규성·배준호 등) 중 최근 출전·득점·부상 이슈가 있는 선수를 골라
   네이버 자동완성으로 수요를 확인한다. 통과하면 그 주제로 확정.
2. **차선(한국 연결 실패 시):** FALLBACK 하지 말고 커뮤니티 2곳 이상에서 반복 언급된 **핫이슈 1건을 그대로 주제**로 확정한다
   (예: `주제: 맨유 차기 감독 논란 - 포체티노 선임설`). 한국 선수 연결·네이버 수요 확인은 요구하지 않는다.
   파일에 "차선: 비한국 핫이슈" 라고 적는다.

3. **루머 대체(2026-11-21):** 위 1·2 모두 관심도가 낮은 후보뿐이면(네이버 자동완성 수요 약함, 커뮤니티 반복 언급 부족)
   **한국 선수와 무관한 재밌는 루머 1건**(실제 보도·유포된 이적설·썰, 출처 2곳 이상, 실존 인물 비방·사생활 제외, 최근 2주 중복 제외)을
   주제로 확정한다. 예: `주제: 음바페 맨유행 썰, 어디서 시작됐나`. 파일에 "루머 대체" 라고 적는다.

## 실패 시 (FALLBACK)
아래일 때만 첫 줄을 `주제: FALLBACK` 으로 쓰고 이유를 적는다. 요일별 고정 주제로 대체된다.
- 커뮤니티 소스를 하나도 못 읽고(Chrome 3회 재시도 실패 포함) WebSearch로도 오늘 기준 핫이슈를 확신할 수 없음.
