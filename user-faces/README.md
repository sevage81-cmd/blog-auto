# user-faces/

선수 카드(`[CARD: ...]`)에 쓸 **베이스 선수 카드**를 구단별로 넣어둔다.

```
user-faces/
  맨유/
    Bruno Fernandes(브루노 페르난데스).png
    Bryan Mbeumo(음뵈모).png
    ...
  맨시티/
    Erling Haaland(홀란드).png
    ...
```

- **폴더** = 구단 (약칭 아무거나 — `맨유`, `맨시티` 등. image-make 가 느슨하게 매칭)
- **파일명** = `영문명(한글별칭).png`. 파일명에 영문 성이나 한글명이 들어가면 매칭된다.
- **내용** = 얼굴 + 이름 배너 + 등번호 + 구단 뱃지까지 완성된 카드.
  **스탯은 비워둔다** — 경기마다 `stamp_card.py` 가 하단에 스탯 패널을 얹는다.
  구단 현재 시즌 유니폼이면 가장 좋다. AI Studio(무료)에서 만들면 된다.

## 동작

- `[CARD: ...]` 마커의 선수가 여기 있으면 → 그 베이스 카드에 경기 스탯 +
  평가 톤(good=밝게 / bad=어둡게)을 얹어 완성.
- 없으면 → Commons 얼굴 사진 + `player-card.html` 템플릿으로 대체 생성
  (유니폼이 옛날 것이거나 두상이 아닐 수 있음).

스쿼드가 바뀌면(이적 등) 해당 선수 파일만 갈아끼우면 된다.
git 에는 올라가지 않는다(`.gitignore`).
