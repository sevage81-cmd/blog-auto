# user-faces/

선수 카드(`[CARD: ...]`)에 쓸 **선수 얼굴 이미지**를 여기에 넣어둔다.

- 파일명 = 선수 한글명 또는 영문명 (예: `브루누 페르난드스.png`, `Bruno Fernandes.jpg`)
- 권장: 정면~반측면 **두상(머리+어깨)**, 세로로 조금 긴 비율, 배경 단순.
  구단 **현재 시즌 유니폼**이면 가장 좋다. AI Studio(무료)에서 만들어도 되고
  자유 라이선스 사진을 써도 된다.
- 여기 파일이 있으면 image-make 가 Commons 검색보다 **먼저** 사용한다.
- 없으면 자동으로 Wikimedia Commons에서 얼굴 사진을 받아 쓴다(유니폼이
  옛날 것이거나 두상이 아닐 수 있음).

스쿼드가 바뀌면(이적 등) 해당 선수 파일만 갈아끼우면 된다.
