# 문체 스타일 가이드 (해외축구 블로그)

> 이 문서는 필자의 과거 글 5편을 분석해 "말투/문체"만 추출한 가이드다.
> 내용·주제는 무시하고, 다른 AI가 이 문서 하나만 봐도 동일한 톤으로
> 글을 쓸 수 있도록 규칙 위주로 정리했다.

---

## 1. 기본 어조 / 종결어미

- 기본 종결어미는 **"~습니다" 하십시오체**. 5편 중 4편이 이 체를 사용.
  - 단, 1편(블로그5)은 예외적으로 **"~다" 평서체(해라체 계열)** 를 처음부터 끝까지 일관되게 사용함.
  - → 두 문체를 섞지 말고, **글 하나 안에서는 반드시 하나의 체만 유지**할 것. 기본값은 "~습니다"체를 권장.
- 딱딱한 격식체는 아니고, 구어체에 가까운 하십시오체. 문장이 짧고 리듬감 있게 끊긴다.
- 단정을 피하고 **완곡하게 추측/전망하는 어미**를 즐겨 씀:
  - ~것으로 예상됩니다 / ~할 예상입니다
  - ~라고 생각됩니다 / ~라고 여겨집니다
  - ~가능성이 큽니다 / ~확률이 높습니다
  - ~것이 분명합니다 (단정적 표현이지만 자주 반복돼 하나의 말버릇)
  - ~전망입니다 / ~지켜봐야 할 전망입니다
  - ~보입니다 (판단·추정을 나타낼 때)
- 확정적 사실 서술에도 "~합니다"보다 "~한 상황입니다", "~한 편입니다" 처럼
  **상태/경향을 완곡하게 묘사하는 명사형 종결**을 선호.

## 2. 문장 호흡 / 문단 구조

- **한두 문장 = 한 문단.** 절대 긴 문단을 만들지 않는다. 3문장 넘어가면 무조건 끊는다.
- 문단과 문단 사이에 **빈 줄(공백 문단)을 넣어 시각적 여백**을 준다. (원문에는 물결/공백 기호로 표시됨)
- 한 문장 자체도 길지 않음. 접속사·연결어미로 두 개 절을 붙이는 정도가 최대치이고,
  세 개 이상의 절을 한 문장에 쑤셔 넣지 않는다.
- 문단이 곧 "생각의 단위"로, 하나의 문단 = 하나의 포인트만 담음. 요약형 짧은 문단(한 줄)도 자주 등장.

## 3. 자주 쓰는 연결어/부사 (말버릇)

아래 표현들이 반복적으로 등장하며, 이 글의 "지문"과도 같은 요소다. 적극 재사용할 것.

- **이기에** (~때문에 대신) — "동기부여 자체가 완전히 다르기에", "결장하는 선수가 너무 많은 것이 아쉽기에"
- **굳이** — "굳이 모험이나 테스트는 필요치 않습니다", "굳이 변화를 가질 이유가 없습니다"
- **일단** (문장 서두에서 화제 전환/우선순위 제시) — "일단 수비수의 부상은 심각합니다"
- **나름** — "나름 중하위권 순위에서 괜찮은 수비력을 지닌", "나름 안정적인 중원"
- **결국** — 논리적 귀결을 이끄는 접속부사로 자주 사용
- **워낙** — "워낙 두꺼운 선수층에", "워낙 비싼 이적료로 인해"
- **그렇다 보니 / 그렇기에** — 인과 연결
- **다만 / 하지만** 으로 문단을 시작하며 앞 내용을 뒤집는 구성 다수
- 숫자·통계를 인용할 때 **"~%를 사용했다", "경기당 ~개", "~위를 기록"** 식으로 구체적 수치를 꼭 곁들임

## 4. 도입부 패턴

- 곧바로 본론(경기/이적 정보)으로 들어가지 않고, **상황 브리핑으로 시작**:
  - 리그 진행 상황, 라운드 수, 순위표 맥락 등 "지금 이 리그가 어떤 국면인가"를 먼저 요약
  - 때로는 **날짜/시간을 숫자로 명시**하며 시작 ("2020년 7월 14일 화 새벽 04시 00분")
  - 때로는 **날씨·계절 잡담으로 가볍게 운을 뗌** ("비는 잠시 그쳤지만, 습도가 무지하게 높아서...")
- 도입부에서 이번 글이 다룰 두 대상(팀/선수)을 자연스럽게 소개하고,
  "그럼 ~살펴봅시다" 같은 **직접적인 전환 문구로 본론 진입**을 알림.
  - 예: "그럼 한번 살펴봅시다.", "그럼 결승전과 같은 두 팀의 대결을 살펴봅시다."

## 5. 본론 전개 방식

- **팀A → 팀B 순서로 대구(對句) 구조** 반복: 한 팀 전술/이슈 설명 후 곧바로 상대 팀도 동일한 틀로 설명.
- 전술 포메이션은 항상 **숫자 조합(4-3-3, 4-2-3-1 등)** 으로 표기하고,
  "이번 시즌 O%의 경기에 이 전술을 사용했다" 식으로 **사용 빈도 데이터**를 곁들여 신뢰도를 높임.
- 부상/결장 정보는 **선수 이름을 나열하고 사유(부상/징계)를 짧게 붙이는 리스트형 문장**으로 처리.
- 필자의 주관적 판단을 넣을 때는 겸양 표현으로 감쌈:
  - "제가 볼 땐", "개인적으로", "저의 주관적인 생각으론"
- 팀/선수를 평가할 때 **장점 언급 뒤 바로 단점을 붙이는 균형잡기 화법**이 자주 나타남
  ("좋은 모습을 보이지만, ~은 아쉽습니다" 류).

## 6. 마무리 패턴

- 결론을 딱 잘라 단정하기보다 **여운을 남기며 열어두는 방식**으로 마무리:
  - ~궁금합니다 / ~지켜봅시다 / ~지켜봐야 할 전망입니다
  - ~관심이 간다 (다체일 때)
  - ~재밌는 경기가 될 것이 분명합니다
- 때때로 **수사적 질문으로 글을 맺는 변주**를 사용:
  - "챔스진출이냐? 유로파리그 진출이냐?"
- 마지막 문장은 짧고, 앞 내용을 한 줄로 요약/재확인하는 성격이 강함. 새로운 정보를 마지막에 던지지 않음.

## 7. 어휘 성향

- 축구 전문용어(포메이션, 결장, 선발, 이적설, 임대, 승격/강등, 챔스/유로파 등)를 설명 없이 그대로 사용.
  → 독자가 축구를 아는 사람이라는 전제.
- 한자어·격식 어휘보다는 **구어적이고 친근한 단어 선택**: "저렴하게 영입하기를 원하는", "돈 벌고 좋아 보이네요" 같은 캐주얼한 코멘트도 섞임.
- 감탄형 짧은 코멘트를 문단 사이에 끼워 넣는 습관: "그냥 쉬면서 돈 벌고 좋아 보이네요.", "결과는 정말 달라졌을 겁니다."
- 강조할 때 "정말", "너무", "굉장히", "매우"를 부담 없이 반복 사용 (과하다 싶을 정도로 강조부사를 자주 씀).

## 8. 그 외 눈에 띄는 특징

- **줄바꿈이 매우 잦다** — 가독성을 위해 한 문장, 한 생각마다 줄을 바꾸는 습관이 뚜렷함 (모바일/블로그 특유의 스크롤 리듬).
- 문단 시작을 접속사(하지만, 그러나, 결국, 여기에, 거기에)로 여는 경우가 많아 **글이 계속 이어지는 대화체 흐름**을 만듦.
- 같은 의미를 여러 번 다른 표현으로 반복 강조하는 경향 있음 (예: 부상 얘기를 여러 문단에 걸쳐 다른 각도로 재확인).
- 특정 선수/팀에 대한 짧은 사견을 괄호 없이 문장 속에 자연스럽게 흘려 넣음 (편집자적 개입이 아니라 대화하듯).
- 통계·나이·국적·데뷔 클럽 등 **프로필형 정보를 나열식으로 소개**하는 문단이 자주 나타남 (이적설/유망주 소개 글에서 두드러짐).

## 9. 신뢰를 얻는 말투/패턴

독자가 "이 사람 진짜 좀 아네" 하고 느끼게 만드는 장치들. 근거를 감추지 않고 계속 노출시키는 게 핵심.

- **숫자로 주장을 뒷받침한다.** 감상 대신 항상 데이터를 붙임.
  - "이번 시즌 모든 경기의 62%를 4-5-1로 경기를 펼쳤지만..."
  - "경기당 인터셉트는 리그에서 3.1개로 1위"
  - "최근 6경기 5승 1패로 압도적인 우위"
  - → 주장 하나마다 최소 하나의 구체적 수치/전적/기록을 붙이는 습관을 재현할 것.
- **팩트와 의견을 명확히 구분해서 표시한다.**
  - "제가 볼 땐", "개인적으로", "저의 주관적인 생각으론" 같은 표현으로
    지금 하는 말이 객관 정보가 아니라 자기 견해임을 스스로 밝힘.
  - → 이 라벨링이 오히려 "이 사람은 정직하게 말한다"는 신뢰를 만든다. 모든 걸 단정하듯 말하지 않는 것.
- **자기 예측에 대한 반례/변수까지 먼저 언급한다.**
  - "물론, 급한 토트넘이기에 조급함이 앞서 실수가 발생할 수도 있고..." 처럼
    자신의 결론과 반대되는 가능성도 인정한 뒤 결론을 내림.
  - → 일방적 확신이 아니라 "여러 변수를 다 검토했다"는 인상을 줘서 설득력이 올라감.
- **근거(이유)를 항상 문장에 붙인다.** "~이기에", "~때문에"로 이유 없는 주장을 남기지 않음.
  - 예: "굳이 변화를 가질 이유가 없습니다" (변화가 없을 거란 주장 + 왜 없는지 이유가 세트로 붙음)
- **과거 사례를 근거로 끌어와 판단의 타당성을 보강한다.**
  - "1패마저도 19년 1월 컵 대회에서의 패배로 출전 선수조차 로테이션 멤버였기에 큰 의미는 없고..."
  - → 단순히 결과만 나열하지 않고, 그 결과가 왜 지금 상황에 적용 가능한지/안 되는지까지 설명.
- **선수/팀 소개 시 이력을 촘촘히 나열한다** (출신 클럽 → 임대 → 현 소속팀 순서).
  - → 정보량 자체가 "이 사람이 조사를 많이 했다"는 신호가 되어 신뢰로 이어짐.

## 10. 독자의 집중을 끄는 말투/패턴

읽다가 이탈하지 않고 끝까지 따라오게 만드는 리듬/장치들.

- **결정적 순간을 "결승전"급 비유로 프레이밍한다.**
  - "사실상의 결승전 같은 분위기인 이번 경기", "결승전과 같은 두 팀의 대결"
  - → 평범한 경기도 긴장감 있는 이벤트처럼 느껴지게 만듦.
- **문단을 궁금증 유발 문구로 끊고 다음 문단으로 넘긴다.**
  - "~궁금합니다", "지켜봅시다", "지켜봐야 할 전망입니다"
  - → 결론을 바로 주지 않고 다음 내용을 계속 읽게 만드는 미끼 역할.
- **수사적 질문으로 긴장을 잠깐 끊어준다.**
  - "챔스진출이냐? 유로파리그 진출이냐?"
  - → 평서문만 이어지던 리듬에 변주를 줘서 환기 효과.
- **"하지만/그러나"로 반전을 자주 배치한다.**
  - 장점 언급 → 반전 → 단점, 혹은 그 반대 순서로 문단을 짜서
    독자가 다음 문장에서 뭐가 나올지 예측 못 하게 함.
- **짧은 문장 + 잦은 줄바꿈으로 스크롤 리듬을 만든다.**
  - 한 문단이 한 화면을 넘기지 않게 끊어서, 읽다가 지치지 않고 계속 내려가게 유도.
- **캐주얼한 감탄/코멘트를 사이사이 배치해 생동감을 준다.**
  - "그냥 쉬면서 돈 벌고 좋아 보이네요." 처럼 툭 던지는 한마디로
    딱딱한 분석 사이에 숨 쉴 틈을 만들어 몰입을 유지시킴.
- **핵심 변수를 마지막까지 아껴뒀다가 마무리 부분에 배치한다.**
  - 예: 글 초중반에 정보를 쌓다가, "결국 ~가 핵심 포인트가 될 전망입니다" 식으로
    마지막에 "그래서 뭐가 제일 중요한가"를 정리해주는 문장을 배치.
  - → 독자가 "결국 이게 요점이구나"라고 느끼며 끝까지 읽은 보람을 얻게 함.

## 빠른 체크리스트 (AI 재현용)

- [ ] 종결어미는 "~습니다"체로 통일했는가 (한 글 안에서 혼용 금지)
- [ ] 한 문단에 문장 1~3개, 그 이상이면 쪼갰는가
- [ ] "이기에", "굳이", "일단", "나름", "결국", "워낙" 중 자연스럽게 몇 개 사용했는가
- [ ] 도입부에 상황 브리핑 + "그럼 ~살펴봅시다" 전환 문구를 넣었는가
- [ ] 전술/데이터를 숫자로 구체화했는가 (포메이션, %, 경기당 수치 등)
- [ ] 장점 언급 뒤 단점(혹은 반대로) 붙이는 균형 화법을 썼는가
- [ ] 마무리는 단정 대신 "궁금합니다/지켜봅시다/전망입니다"류로 여운을 남겼는가
- [ ] 과한 단정 대신 "~것으로 예상됩니다/생각됩니다/여겨집니다"로 완곡화했는가
- [ ] 주장마다 구체적 수치/전적 등 근거를 붙였는가 (신뢰)
- [ ] 팩트와 개인 의견을 "제가 볼 땐" 등으로 구분해서 표시했는가 (신뢰)
- [ ] 결론과 반대되는 변수/반례도 한 번은 언급했는가 (신뢰)
- [ ] 궁금증을 유발하는 문구로 문단을 끊어 다음 내용을 기대하게 했는가 (집중)
- [ ] 핵심 요점을 마지막까지 아꼈다가 마무리에서 정리했는가 (집중)
