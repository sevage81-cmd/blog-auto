# 이미지 제작 가이드 (image-make 에이전트용)

> 이 문서는 `image-make` 에이전트가 블로그용 이미지를 만들 때 따르는 가이드다.
> 대표 이미지 1종 + 본문 삽입 이미지 규칙을 정리했다.

> 아래 규격은 `guides/image-templates/`에 실제 HTML/CSS로 이미 구현돼 있다.
> image-make 에이전트는 보통 이 문서를 처음부터 해석해서 HTML을 새로
> 작성하지 않고, `guides/image-templates/README.md`를 보고 템플릿에 내용만
> 채운다. 이 문서는 그 템플릿들이 따르는 디자인 규격 정의, 그리고 템플릿에
> 안 맞는 예외 케이스를 직접 만들 때 참고하는 기준이다.

---

## 1. 대표 이미지 규격

- **크기**: 가로 1080px × 세로 1080px (1:1 정사각형)
- **배경**: 기본 테마는 밝은 블루-그린 그라데이션 (`#2f6f8f` → `#3a9b73`) — 밝은 중계
  화면 톤의 경기장 그라운드를 연상시키는 톤. 요일별로 이 배경·포인트 컬러가
  바뀐다 (아래 "1-2. 요일별 테마" 참고). 배경에 은은하게 **센터서클/하프라인
  같은 피치 라인 패턴**을 옅은 투명도(약 15%)로 깔아 축구 콘텐츠라는
  느낌을 준다.
- **보조 텍스트 색**: 배경이 밝으므로 회색이 아니라 **밝은 민트-화이트
  계열**(`#e4efeb`~`#d7e5e1`)을 쓴다. 흰색 제목과 피치 그린 포인트
  (`#4ade80`)는 그대로 유지한다.
- **제목 텍스트를 넣지 않는다**: 네이버 블로그 목록뷰는 썸네일 위에 실제 글
  제목을 직접 겹쳐서 보여준다. 썸네일 안에도 큰 제목 글씨를 넣으면 두 텍스트가
  겹쳐 가독성이 망가진다(대표 이미지 = 글 제목 X). 그래서 텍스트는 좌상단
  카테고리 뱃지 하나뿐이고, 나머지는 텍스트 없는 그래픽 엠블럼으로 채운다.
- **뱃지**: 좌상단 고정. 카테고리/시리즈명 등 짧은 라벨(작은 글씨, 각진
  뱃지/캡슐 박스, `var(--accent)` 테두리).
- **중앙 그래픽**: 화면 정중앙에 원형 엠블럼(점선 링 + 축구공 라인 아이콘)을
  크게 배치해 "스코어보드/방송 그래픽" 느낌을 살린다. 글마다 달라지는 텍스트가
  없어도 배경 테마 색과 피치 라인 패턴만으로 구분된다.
- **포인트 컬러**: 잔디를 연상시키는 **피치 그린 계열(예: `#4ade80` 또는
  `#22c55e`)**을 한 곳(엠블럼 링, 하단 강조선, 뱃지 테두리 등)에만 절제해서 사용한다.
- **액센트**: 중앙 엠블럼 외에 별도 액센트 요소는 두지 않는다(과하게 채우지
  않는다). 축구공 라인 아이콘 하나로 축구 콘텐츠라는 느낌을 준다.

## 1-2. 요일별 테마 (대표 + 본문 공통)

주제(요일)에 따라 이미지의 **배경 그라데이션과 포인트 컬러**가 바뀐다.
레이아웃·폰트·크기·구성요소는 그대로다 — 색만 갈아끼운다. 색 값은
`agents/scripts/build_images.py`의 `THEMES`에 정의돼 있고, image-make는
`spec.json`의 각 이미지 항목에 `"theme": "<이름>"`만 넣으면 된다.

| 요일 | 주제 성격 | theme 이름 | 컨셉 |
|---|---|---|---|
| 일 / 월 | EPL 경기 결과 리뷰 | `epl-result` | 프리미어리그 퍼플, 결과·정리 톤 (차분한 딥 퍼플 + 그린) |
| 토 | EPL 주말 전망 | `epl-preview` | 프리미어리그 퍼플, 기대·프리뷰 톤 (밝은 퍼플 + 시안) |
| 화 | 라리가·세리에A·분데스 주말 리뷰 | `euro-result` | 유럽 3리그 결과, 와인·차콜 + 골드 |
| 금 | 유럽 리그 주말 전망 | `euro-preview` | 유럽 3리그 프리뷰, 딥 블루 + 옐로우 |
| 수 | 한국인 해외파 주요 선수 | `kor-star` | 태극 느낌, 네이비 + 레드 |
| 목 | 한국인 유망주·하부리그 | `kor-youth` | 성장·신예 느낌, 딥 그린 + 라임 |
| (그 외 / 자유 주제) | — | 생략 또는 `default` | 기존 블루-그린 피치 톤 |

색 톤을 바꾸고 싶으면 `THEMES` 딕셔너리의 `(배경, 포인트, 강조)` 3개 값만
고치면 모든 템플릿에 반영된다.

## 2. 본문 삽입 이미지 종류

글 내용에 맞게 아래에서 선택해서 사용한다. 1~4는 템플릿에 내용을 채워 만드는
그래픽 카드, 5는 사진(실사진 + 실사 유사 이미지)이다.

1. **비교 표** — 제품/방법을 나란히 비교할 때
2. **단계별 다이어그램** — 절차나 순서를 보여줄 때
3. **핵심 포인트 카드** — 3~5개 요점을 정리할 때
4. **인용/강조 박스** — 중요한 한 마디를 강조할 때
5. **사진** — 그래픽 카드만 있으면 글이 밋밋하고 D.I.A가 원본성·경험 신호로
   덜 쳐주므로(seo-guide.md 4장 "원본성" 참고), **글마다 최소 5장, 그래픽
   카드 수 이상**을 사진으로 넣는다. 카드(1~4)는 순위표·스코어 요약 같은
   진짜 데이터일 때만 쓰고 글당 2개까지다. **(a) Commons 실사진이 기본이고
   우선**이다 — 특정 대상이든 분위기·장면이든 먼저 Commons에서 찾는다.
   - **(a) Commons 실사진** — 특정 경기장·선수·트로피 등 실제 대상은 그 고유명사로,
     조명 아래 피치·관중석·세리머니 실루엣 같은 분위기·장면은 "football stadium
     crowd", "football fans celebrating goal" 같은 일반 영문 키워드로 검색한다
     (이번 주 이 경기 사진일 필요 없음). Wikimedia Commons에서만 가져오고
     (저작권 안전), 저작자·라이선스 캡션 필수. 인물 클로즈업은 요일별 theme
     듀오톤으로 가공해 원본과 다른 톤으로 바꿔 쓴다(경기장 등 비인물 사진은
     원본 그대로).
   - **(b) AI 생성 분위기 컷 — 사용 중단**(화질 허접. 사진 자리에 쓰지 않는다. 아래는 참고용) — Commons 검색을 여러 번 시도해도
     못 채운 자리에만 쓴다. 무료 백엔드(Pollinations/Flux)는 화질이 낮고
     워터마크가 남는 한계가 있다. `gen_image.py`가 생성하며, **실존 선수
     얼굴·구단 로고는 넣지 않는다**(실루엣·군중·원경까지). 캡션에 "AI 생성
     이미지 (실제 사용된 백엔드명)"을 밝힌다.
   **중복 금지:** 이미 쓴 사진과 너무 비슷한 사진(같은 장면·같은 포즈·같은 원본)은 보류하고 다른 것을 쓴다.
   **관련성 최우선:** 글 내용(해당 문단의 팀·선수·경기)과 직접 이어지지 않는 사진은
   장수가 모자라도 쓰지 않는다. 대신 검색 범위를 넓혀 5장을 채우고, 그래도 부족하면 보고한다.
   소싱·캡션 절차는 `agents/image-make.md`, 스크립트는
   `agents/scripts/fetch_photo.py`(a) / `agents/scripts/gen_image.py`(b) /
   `agents/scripts/stylize_photo.py`(듀오톤 가공) 참고.

6. **선수 카드** (`[CARD: ...]`) — 경기 결과 리뷰형 주제(일·월)에서 리뷰
   대상 경기마다 그 경기 핵심 선수 1명, 인물 나열 근황형 주제(수·목)에서
   경기 기록이 있는 선수마다, 단독형·프리뷰형 주제(화·토)에서 경기마다 뽑은
   "가장 기대되는 선수"마다 트레이딩 카드로. 프리뷰형은 아직 이번 경기
   스탯이 없으니 `스탯` 필드에 직전 경기 기록(최근 폼)을 대신 쓴다. 디자인
   레퍼런스는 `guides/image-templates/player-card-ref.png` (이름 배너 + 얼굴 +
   큰 스탯 + 등번호 + 구단 뱃지 + 초록 프레임).
   - **경로 A (기본): `user-faces/` 베이스 카드 + `stamp_card.py`** —
     사용자가 만들어 둔 완성형 베이스 카드(얼굴·이름·등번호·뱃지)에 경기
     스탯 패널과 평가 톤(good=밝게 / bad=어둡게)만 얹는다. 무료·자동.
     EPL 클럽 소속 선수는 `user-faces/<구단>/`에서, 수·목요일 고정 명단
     선수(해외파·유망주)는 `user-faces/수요일/`, `user-faces/목요일/`에서
     찾는다 — image-make가 이름으로 전체 하위폴더를 뒤져 매칭한다.
   - **경로 B: `player-card.html` 템플릿 + 얼굴 사진** — 베이스 카드가 없는
     선수(상대팀, 명단에 없는 선수 등). `fetch_photo.py` Commons 얼굴 +
     `build_images.py` 렌더.
   - **선택: AI 생성 카드(`gen_image.py --card`)** — `GEMINI_API_KEY` + 크레딧이
     있을 때. 진짜 표정·최신 유니폼까지. 캡션에 "AI 생성 선수 카드".
   - 팬/에디토리얼 그래픽이고 표시 스탯은 research.md 기준 사실만, 짧게.

## 3. 공통 규칙

- 모든 이미지는 **HTML + CSS**로 만들고, **Python + Playwright**를 실행해서
  **PNG로 캡처**한다.
- 배경 톤은 본문과 어울리게 **해외축구/스포츠 중계 분위기**(밝은 중계 화면,
  블루-그린 톤, 스코어보드·방송 그래픽 느낌)로 맞춘다.
- 텍스트는 **최대한 짧게** 쓴다. 이미지는 보조 수단이지 본문을 대신하는
  것이 아니다.
- **스포츠 스코어보드/중계 그래픽 스타일**(각진 뱃지, 얇은 강조선, 피치
  그린 포인트 컬러, 숫자를 강조하는 스코어보드풍 폰트 굵기)을 디자인
  요소로 활용할 수 있다. 포메이션 숫자(4-3-3 등)나 순위·수치 데이터를
  다루는 이미지에서는 이 스코어보드 톤을 적극 살린다.
